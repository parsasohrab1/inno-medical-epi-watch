# کارت داده — inno-medical-epi-watch

- **منبع:** کاملاً مصنوعی؛ تولید با `python -m inno_medical_epi_watch generate --seed N` (قطعی). هیچ داده‌ی بیمار، شخص یا مرکز واقعی در ریپو نیست.
- **نمونه‌ی ذخیره‌شده:** `data/sample/*.csv` (seed=0).
- **فرض‌ها:** ۱۲ استان × ۳ بیماری × ۲۶۰ هفته؛ ۱۴ طغیان تزریق‌شده؛ تأخیر گزارش‌دهی و تغییر تعریف مورد در داده مدل نشده است.
- **استفاده‌ی مجاز:** توسعه و آزمون نرم‌افزار. استفاده برای آموزش/ارزیابی مدل بالینی یا هر تصمیم واقعی مجاز نیست.
- **حریم خصوصی:** هنگام ورود داده‌ی واقعی باید بی‌نام‌سازی، مجوز اخلاق و توافق‌نامه‌ی اشتراک داده انجام شود.
