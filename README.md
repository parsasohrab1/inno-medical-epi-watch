# inno-medical-epi-watch

**پایش اپیدمیولوژیک برای وزارت**

> وضعیت: **TRL 4** — نمونه‌ی آزمایشگاهی با اعتبارسنجی اجزا روی **داده‌ی مصنوعی** (بدون داده‌ی بیمار). برای ارزیابی بالینی یا میدانی آماده نیست. ← [مستندات TRL](docs/TRL.md)

## نیاز شناسایی‌شده
پراکندگی داده‌ی بیماری‌های واگیر و غیرواگیر و تأخیر در گزارش استانی.

## محصول
داشبورد و پیش‌بینی روند بیماری‌ها در سطح استان و شهرستان.

## کاربران و ذی‌نفعان
معاونت بهداشت، مراکز بهداشت استان

## قابلیت‌های هدف
- پیش‌بینی روند بیماری‌های منتخب
- تشخیص جهش غیرعادی
- گزارش استانی خودکار

## داده
گزارش مراکز بهداشت، سن، جنس، منطقه. در مراحل اولیه فقط داده‌ی مصنوعی یا بی‌نام‌شده استفاده می‌شود.

## ریسک‌ها و محدودیت‌ها
تأخیر و ناقص بودن گزارش‌ها؛ تفاوت تعریف مورد.

## مسیر پیشنهادی
1. ✅ TRL 1 → 2: تعریف نیاز و معیار موفقیت (جدول معیارها در [docs/TRL.md](docs/TRL.md)).
2. ✅ TRL 3: نمونه‌ی آزمایشگاهی روی داده‌ی مصنوعی همراه با تست.
3. ✅ TRL 4: اعتبارسنجی اجزا در آزمایشگاه با تست‌های خودکار (CI روی هر push).
4. ⬜ TRL 5: اعتبارسنجی در محیط مرتبط با داده‌ی واقعی بی‌نام‌شده — نیازمندی‌ها در [docs/TRL.md](docs/TRL.md).

## یادداشت
این ریپو بخشی از مجموعه‌ی `inno-medical-*` برای دانشگاه‌های علوم پزشکی و وزارت بهداشت است. هیچ‌یک از خروجی‌ها جایگزین قضاوت بالینی نیست.

## راه‌اندازی سریع
```bash
pip install -r requirements.txt           # فقط numpy
export PYTHONPATH=src
python -m inno_medical_epi_watch generate --out data/sample # تولید داده‌ی مصنوعی (قطعی با seed)
python -m inno_medical_epi_watch validate                   # اجرای معیارهای TRL 4 روی ۳ seed
python -m inno_medical_epi_watch demo
python -m unittest discover -s tests -v
```

## آنچه پیاده‌سازی شده
تشخیص جهش با انتظار فصلی (۳ سال قبل، ±۲ هفته) و آستانه‌ی پواسون، پیش‌بینی ۴ هفته‌ای، `provincial_report` برای گزارش استانی.
